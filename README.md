# Acervo de estudos de componentes React

Este projeto é um acervo didático para estudar conceitos fundamentais do React. Cada tópico tem uma página própria com explicações e exemplos práticos para ajudar a entender como o conceito funciona e como aplicá-lo.

## Deploy

Acesse a versão publicada: [frontend-components-study-screen.vercel.app](https://frontend-components-study-screen.vercel.app/)

## Conceitos abordados

1. **JSX** — escrita de interfaces com uma sintaxe semelhante a HTML.
2. **Componentes** — divisão da interface em partes reutilizáveis.
3. **Props** — passagem de informações entre componentes.
4. **Virtual DOM** — atualização da interface conforme os dados mudam.
5. **Listas e keys** — renderização de coleções com `map()` e identificação dos elementos com `key`.
6. **Renderização condicional** — exibição de conteúdos diferentes conforme uma condição.

Na página inicial, escolha um conceito para abrir suas explicações e exemplos. Use a opção de voltar para retornar à lista.

## Executar localmente

Requer Node.js e npm instalados.

```bash
npm install
npm run dev
```

Para gerar a versão de produção:

```bash
npm run build
```
