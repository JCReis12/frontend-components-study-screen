# React em prática

Uma plataforma de estudo interativa para aprender os fundamentos do React. Cada conceito reúne uma explicação, exemplos de código, uma prática para experimentar na própria página e um desafio rápido para continuar aprendendo.

## Acesse o projeto

[Abrir o deploy](https://frontend-components-study-screen.vercel.app/)

## Trilha de fundamentos

1. **JSX** — descreva interfaces com marcação dentro do JavaScript e veja expressões atualizarem a página.
2. **Componentes** — componha interfaces com funções reutilizáveis.
3. **Props** — passe dados do componente pai para o filho e personalize exemplos em tempo real.
4. **Renderização e Virtual DOM** — entenda o ciclo de render e commit do React; a comparação visual é identificada como uma simulação didática.
5. **Listas e keys** — renderize coleções com `map()` e pratique a identificação estável dos itens.
6. **Renderização condicional** — alterne estados para mostrar ou ocultar partes da interface.

Marque os conceitos concluídos para acompanhar seu progresso durante a visita. Cada aula também oferece navegação para o tópico anterior ou seguinte e um link para a documentação oficial do React.

## Executar localmente

Requer Node.js e npm.

```bash
npm install
npm run dev
```

Para gerar a versão de produção:

```bash
npm run build
```
