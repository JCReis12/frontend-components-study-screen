# React em prática

Uma plataforma de estudo interativa para aprender os fundamentos do React. Cada conceito reúne explicações, exemplos de código, uma demonstração interativa e uma prática curta em um editor temático. Se a pessoa parar de digitar, o editor oferece uma sugestão opcional que pode ser aceita com Tab.

## Acesse o projeto

[Abrir o deploy](https://frontend-components-study-screen.vercel.app/)

## Trilha de estudos

1. **JSX** — descreva interfaces com marcação dentro do JavaScript e veja expressões atualizarem a página.
2. **Componentes** — componha interfaces com funções reutilizáveis.
3. **Props** — passe dados do componente pai para o filho e personalize exemplos em tempo real.
4. **Renderização e Virtual DOM** — entenda o ciclo de render e commit do React; a comparação visual é identificada como uma simulação didática.
5. **Listas e keys** — renderize coleções com `map()` e pratique a identificação estável dos itens.
6. **Renderização condicional** — alterne estados para mostrar ou ocultar partes da interface.
7. **Estado e `useState`** — guarde valores entre renderizações e atualize a interface.
8. **Formulários** — trabalhe com campos controlados, validação e envio.
9. **`useEffect`** — sincronize componentes com sistemas externos e limpe temporizadores.
10. **Consumo de APIs** — trate carregamento, respostas, erros e cancelamento de requisições.
11. **React Router** — relacione URLs e telas e navegue sem recarregar o documento.

Marque os conceitos concluídos para acompanhar seu progresso durante a visita. As aulas oferecem navegação entre tópicos, referências para aprofundar e desafios de digitação de código. O código digitado no editor de prática é comparado com a resposta esperada e não é executado.

## Executar localmente

Requer Node.js e npm.

```bash
npm install
npm run dev
```

Para gerar a versão de produção:

```bash
npm run build
```
